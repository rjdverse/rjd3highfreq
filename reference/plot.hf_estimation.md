# Plot method for hf_estimation objects

Plot method for hf_estimation objects

## Usage

``` r
# S3 method for class 'hf_estimation'
plot(
  x,
  ...,
  col_bg = "#ffffe0",
  col_grid = "#777777",
  col_labels = "#777777",
  col_1 = "#debc12",
  col_2 = "#74b6d6"
)
```

## Arguments

- x:

  An object of class `JDFractionalAirlineDecomposition`.

- ...:

  additional options for first line.

- col_bg:

  Background color.

- col_grid:

  Color of grid lines.

- col_labels:

  Color of tick labels.

- col_1:

  First time series color.

- col_2:

  Second time series color.

## Value

`x`, invisibly.

# Plot method for hf_decomposition objects

Plot method for hf_decomposition objects

## Usage

``` r
# S3 method for class 'hf_decomposition'
plot(
  x,
  ...,
  col_bg = "white",
  col_grid = "#777777",
  col_labels = "#777777",
  col_1 = "#debc12",
  col_2 = "#74b6d6",
  col_3 = "#ee2c2c"
)
```

## Arguments

- x:

  An object of class `hf_decomposition`.

- ...:

  options for par()

- col_bg:

  Background color.

- col_grid:

  Color of grid lines.

- col_labels:

  Color of tick labels.

- col_1:

  First time series color.

- col_2:

  Second time series color.

- col_3:

  Third time series color.
